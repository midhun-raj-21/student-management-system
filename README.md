# Student Management System

A full-stack Student Management System built using Spring Boot, MySQL, HTML, CSS, JavaScript, and Bootstrap.

## Features

* Add Student
* View Students
* Update Student
* Delete Student
* Search Students
* Student Counter Dashboard
* Form Validation
* REST APIs
* MySQL Database Integration

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap
* Git & GitHub
