# Student Management System

## Overview

A full-stack web application developed using Spring Boot, MySQL, HTML, CSS, JavaScript, and Bootstrap to manage student records.

## Features

* Add Student
* View Students
* Update Student
* Delete Student
* Search Students
* Student Counter
* Form Validation
* REST APIs

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap
* Git & GitHub

## Project Structure

Controller → Service → Repository → Database

## Steps to Run

1. Clone repository
2. Configure MySQL
3. Update application.properties
4. Run Spring Boot
5. Open frontend/index.html

## Challenges Faced

* MySQL connection issues
* CORS errors between frontend and backend
* Validation handling
* CRUD API integration

* Spring Boot REST APIs
* JPA/Hibernate
* MySQL Integration
* Git & GitHub
